# Image prompts

Ready-to-paste prompts for every **photo** slot on the site (36 images). Rows are grouped by page. Slots that are not photos are listed at the end.

## How to use
1. Generate each image at the **aspect ratio** shown (Midjourney: add `--ar W:H`; other tools: pick the nearest ratio). Generate bigger if your tool allows, then resize to the exact **Final size**.
2. Save as a JPG with the **exact file name** in `assets/img/` (overwrite the old file).
3. Rebuild the WebP twin: `cd _dev/build && npm install && npm run webp`.
4. Check the page in a browser. Edges of the hero photos fade out with CSS, so keep the subject away from the edges.

**Consistency tips**
- Generate `hero-1.jpg` first. Use it as the *face reference* (character/image reference) for `hero-chip-avatar.jpg` so it is the same woman.
- Every other face is a **different person**, see the casting list below. Keep the casting details in the prompt when you re-roll.
- Prompts already contain the shared photo look and the shared "avoid" list. Do not shorten them.

### The shared photo look (already inside every prompt)
> Photorealistic candid photograph, shot on a full-frame DSLR with a 50mm or 85mm lens at f/1.8, natural soft window light, shallow depth of field, tack-sharp eyes and face, real skin texture with visible pores and fine peach fuzz, natural imperfections, no airbrushing, no plastic skin, subtle film grain. Warm, cozy Indian home or café setting. Colour mood: warm whites, soft blush pink and rose tones, creamy highlights.

### The shared "avoid" list (already inside every prompt)
> No text, no logos, no watermarks, no captions, no signage. No extra fingers, no deformed hands. No phone screen content (phones are held with the back facing the camera, or the screen is off). No plastic or airbrushed skin, no cartoon or 3D-render look, no heavy HDR, no oversaturated colours.
