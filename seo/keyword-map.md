# feelytalk.com keyword map (Phase 2)

Date: 2026-10-08. **No GSC data was available** (see audit.md section 5). This map comes from each page's existing content and from search intent for an Indian talk/chat-with-hosts app. No search volumes are claimed. Revisit it once GSC has 4–8 weeks of query data.

Rules used:
- One primary keyword per URL, so pages don't compete with each other.
- Only keywords the page's copy already supports. There is no "earn money" angle: payout copy is unconfirmed (help.html placeholder), so no page promises earnings.
- I avoided "strangers" and "random video chat". The product is friendly hosts, and those terms pull the wrong intent and safety associations.
- Title of 60 characters or fewer, ending in "| FeelyTalk" except on home, where the brand leads. Description of 140–155 characters.
